                  验证码机制详细说明文档
================================================================================

一、概述
================================================================================
本验证码机制是一种基于日期的动态密码验证系统，用于保护正版授权内容。
用户需要输入当日有效的4位验证码才能访问应用核心功能。

核心特点：
- 验证码每日自动更新，基于日期算法生成
- 一次验证后，同一设备无需重复验证（通过localStorage持久化）
- 验证失败后提供客服联系方式
- 支持回车键快速提交验证


二、验证码生成算法
================================================================================

算法公式：(月份³ + 日期³) + 2000，转16进制取后4位

示例计算：
- 4月4日：4³ + 4³ + 2000 = 64 + 64 + 2000 = 2128 → 0x850 → 0850 → 0850
- 3月15日：3³ + 15³ + 2000 = 27 + 3375 + 2000 = 5402 → 0x151A → 151A
- 12月25日：12³ + 25³ + 2000 = 1728 + 15625 + 2000 = 19353 → 0x4B99 → 4B99

JavaScript实现代码：
```javascript
function generateTodayPassword() {
    const now = new Date();
    const month = now.getMonth() + 1;  // 1-12
    const day = now.getDate();          // 1-31

    // (月份³ + 日期³) + 2000
    const num = Math.pow(month, 3) + Math.pow(day, 3) + 2000;

    // 转为16进制（0-9, A-F）
    const hex = num.toString(16).toUpperCase();

    // 取后4位
    const password = hex.slice(-4);

    return password;
}
```

五、JavaScript核心逻辑
================================================================================

1. 初始化流程 (window.onload)
   - 调用 checkAuth() 检查验证状态

2. checkAuth() 函数
   - 检查 localStorage 中的 'tcm_auth_passed' 标记
   - 如已验证：隐藏遮罩层，调用 init() 初始化应用
   - 如未验证：显示遮罩层，聚焦输入框，绑定回车事件

3. verifyPassword() 函数
   - 获取用户输入并转大写
   - 调用 generateTodayPassword() 获取当日正确密码
   - 验证成功：
     * 标记设备已验证 (markDeviceVerified)
     * 显示成功动画
     * 禁用按钮
     * 1.2秒后隐藏遮罩层，初始化应用
   - 验证失败：
     * 显示错误样式和提示
     * 清空输入框
     * 500ms后显示客服联系弹窗

4. markDeviceVerified() 函数
   - 写入 localStorage.setItem('tcm_auth_passed', 'true')
   - 同时保留旧版设备指纹记录（兼容）

5. 设备指纹生成 (generateDeviceFingerprint)
   - 组合：userAgent + screen分辨率 + colorDepth + timezone + language + platform
   - 简单哈希算法生成唯一ID

3. JavaScript函数（放在 <script> 标签中）：
```javascript
// 生成今日密码
function generateTodayPassword() {
    const now = new Date();
    const month = now.getMonth() + 1;
    const day = now.getDate();
    const num = Math.pow(month, 3) + Math.pow(day, 3) + 2000;
    return num.toString(16).toUpperCase().slice(-4);
}

// 检查是否已验证
function isDeviceVerified() {
    return localStorage.getItem('tcm_auth_passed') === 'true';
}

// 标记设备已验证
function markDeviceVerified() {
    localStorage.setItem('tcm_auth_passed', 'true');
}

// 验证密码
function verifyPassword() {
    const input = document.getElementById('authPassword');
    const errorMsg = document.getElementById('authErrorMsg');
    const entered = input.value.trim().toUpperCase();
    const correct = generateTodayPassword();

    if (entered === correct) {
        markDeviceVerified();
        document.getElementById('authOverlay').classList.add('hidden');
        initApp(); // 这里调用你的应用初始化函数
    } else {
        input.classList.add('error');
        errorMsg.classList.add('show');
        input.value = '';
    }
}

// 页面加载时检查
window.onload = function() {
    if (isDeviceVerified()) {
        document.getElementById('authOverlay').classList.add('hidden');
        initApp();
    } else {
        document.getElementById('authPassword').focus();
        document.getElementById('authPassword').addEventListener('keypress', function(e) {
            if (e.key === 'Enter') verifyPassword();
        });
    }
};
```

八、注意事项
================================================================================

1. localStorage 在某些隐私模式下可能不可用，需要添加 try-catch 异常处理

2. 验证码不区分大小写，系统会自动将输入转为大写比较

3. 设备验证标记是持久化的，清除浏览器数据后会重新验证

4. 验证码每日凌晨0点自动更新

5. 此机制适用于轻度版权保护，不能防止技术破解

6. 移动端适配：输入框在移动端需要调整字体大小和内边距
